## Key Concepts Practiced

### 1. List Comprehension

List comprehension provides a concise way to create a new list from existing data.

### 2. Transformation

Each element of an existing list can be transformed into a new value.

### 3. Filtering

Conditions can be used to select only specific elements from a list.

### 4. Combining Logic

List comprehension combines iteration, transformation, and conditional logic into a compact expression.
