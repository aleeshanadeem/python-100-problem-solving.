## 🧠 Key Concepts Learned

### 1. `if`

The `if` statement runs a block of code when a condition is true.

```python
if condition:
    # code
```

---

### 2. `elif`

`elif` allows us to check another condition when the previous condition was false.

```python
if condition1:
    # code
elif condition2:
    # code
```

---

### 3. `else`

`else` handles the remaining case when none of the previous conditions are true.

```python
if condition:
    # code
else:
    # code
```

---

### 4. Comparison Operators

Decision-making often requires comparison operators:

```text
>     Greater than
<     Less than
>=    Greater than or equal
<=    Less than or equal
==    Equal to
!=    Not equal to
```
