# Operators — Python Problems 011–020

## 📌 Overview

This folder contains **10 Python problem-solving questions** focused on Python operators.

The goal of this batch was not only to learn operators, but to practice how operators are used to solve real problems.

---

## 🎯 Learning Objectives

After completing these 10 problems, I practiced:

* Arithmetic operators
* Remainder operator `%`
* Division `/`
* Floor division `//`
* Exponentiation `**`
* Percentage calculations
* Formula implementation
* Unit conversion
* Digit extraction
* Combining multiple operators
* Basic decision-making using operators
