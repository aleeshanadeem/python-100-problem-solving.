# 11 - Dictionaries

This folder contains Python problem-solving exercises focused on **Dictionaries**.

The goal of this batch is to build practical understanding of key-value data, dictionary access, searching, updating, iteration, and working with dictionary values.

## Learning Objectives

By completing these problems, I practiced:

* Creating dictionaries
* Storing data using key-value pairs
* Accessing dictionary values
* Searching for keys
* Updating dictionary values
* Iterating through dictionary data
* Performing calculations using dictionary values
* Finding the highest value without using `max()`
* Handling real-world style data using dictionaries
