## Key Concepts Practiced

### 1. Function Definition

Functions allow us to create reusable blocks of code.

```python
def function_name():
    # code
```

### 2. Function Arguments

Arguments allow us to pass data into a function.

### 3. Return Values

The `return` statement sends a result back from the function.

### 4. Function Calling

After defining a function, it can be called whenever its functionality is needed.

### 5. Reusability

Functions reduce repeated code and make programs easier to organize and maintain.
