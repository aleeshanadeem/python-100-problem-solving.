## Key Concepts Practiced

### Lambda Functions

Lambda functions provide a concise way to create small functions.

### `map()`

`map()` applies a function to each item in an iterable.

### `filter()`

`filter()` selects items based on a condition.

### Combining Operations

Multiple operations can be combined to process data step by step.
